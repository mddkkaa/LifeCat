# LifeCat

Браузерная онлайн-игра о племенах диких котов.

## Что уже есть
- Регистрация и вход
- Создание кота (имя, пол, племя)
- Настройка окраса
- Профиль кота с лунами, ID, активностью
- Загрузка аватарки
- Смена пароля и email
- Удаление кота с отменой

## Стек
- Node.js + Express
- SQLite (better-sqlite3)
- JWT + bcrypt
- Чистый HTML/CSS/JS на фронте
